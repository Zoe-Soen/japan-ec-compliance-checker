# 日本 EC 网站合规 Checker

> 更新时间：2026-08-31  
> 上一版：`demo/` 中的纯模拟界面

这是一个可以完全在本机运行的 MVP 基础版。它会实际读取公开网站页面，按照 30 条保守型规则生成带页面证据、判断说明和整改建议的风险报告，并把检查记录保存在本机数据库中。

## 现在已经可以做什么

- 按“网站信息 → 检查范围 → 自动扫描 → 风险报告”完成一次检查。
- 实际读取同一网站下最多 30 个公开页面，不登录、不提交表单、不创建订单。
- 检查特商法基础信息、最終確認画面、广告表示和日本在地化等 30 个项目。
- 区分“问题、通过、无法确认、不适用”，避免把没有证据的项目误判为通过。
- 保存检查历史、页面快照、规则结果和本次用量。
- 复制单项整改建议，或导出一份 HTML 报告。

## 第一次在本机启动

前提：电脑已安装并打开 Docker Desktop，并安装 Node.js 22 或更高版本。

```bash
npm install
cp .env.example .env.local
npm run setup:local
npm run dev
```

看到启动完成后，在浏览器打开：<http://localhost:4173/>

以后再次启动通常只需要：

```bash
npm run db:up
npm run dev
```

按 `Control + C` 可停止网站和扫描程序。检查记录仍会保留。需要停止本地数据库时运行 `npm run db:down`。

## 当前边界

- 目前只检查无需登录即可访问的公开页面。
- 最終確認画面通常需要实际购物操作或截图 OCR，本版会诚实标记为“无法确认”。
- 暂未接入账号、支付、云端同步、PDF 报告和增量商品检查。
- 自动结果是风险筛查，不构成法律意见或合规认证；重要结论仍应由熟悉日本电商法规的专业人士确认。

## 本地数据与安全边界

检查记录保存在 Docker 中的本地 PostgreSQL 数据库，不会自动上传到云端。扫描器只允许 `http`／`https` 公网地址，并拒绝本机、内网、云元数据地址、URL 凭据和特殊端口；同时拦截跨站跳转以及图片、媒体和字体等非必要资源。
